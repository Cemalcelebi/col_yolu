- d = pencerede en düşük Low'un günü, d <= t − 5 (eşitlikte en son); dip çizgisi = Low(d).
- P1 DÜŞÜŞTEN DİP: d'den önceki pencere kısmında en yüksek High / Low(d) − 1 >= 0,20.
- P2 DÜŞEN TREND KIRILIMI: d'den önceki pivot tepeler (High, 5 sol / 5 sağ mum; pivot günü + 5 <= d). H1 = d'den önceki en yüksek pivot tepe; H2 = H1'den sonra ve d'den önce gelen, H1'den alçak SON pivot tepe (yoksa H1'den sonraki en yüksek pivot tepe; o da yoksa P2 = YOK). Düşen çizgi = H1 ile H2'den geçen doğru (eğim < 0 olmalı; değilse P2 = YOK). Kırılım = d'den sonra (d < i <= t) en az bir mumun KAPANIŞI doğrunun o gündeki değerinin üstünde.
- P3 ARTIK DÜŞMÜYOR, DAHA YUKARIDAN DÖNÜYOR: (i) d'den sonra hiçbir Low < Low(d) (dip delinmez); (ii) d'den sonra en az bir pivot dip (Low, 3 sol / 3 sağ; pivot günü + 3 <= t) var ve bu pivot diplerin HEPSİ Low(d) + 0,5 x ATR14(d) üstünde; (iii) birden çok pivot dip varsa son pivot dip, ilkinden düşük değil.
- V1 (ANA) = P1 ∧ P2 ∧ P3; V2 = P1 ∧ P3 (trend kırılımı yok); V3 = P1 ∧ P2 ∧ P3(i) (yükselen dip yok, yalnız delinmeme). Bonferroni 3.
